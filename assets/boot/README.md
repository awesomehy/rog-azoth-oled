# 启动动画

- `windows.gif`：Windows 图标、`<SYSTEM BOOTING>` 和等待跑马灯。
- `apple.gif`：备用苹果图标版本，其他布局和动画与 Windows 版本一致，目前不用于键盘显示。

两份文件均为 208×64、36 帧、每帧 60 毫秒、2.16 秒无限循环的灰阶 GIF。有线和 2.4GHz 均使用 Windows 版；这不代表键盘识别了电脑操作系统。

后台在初始化时播放动画，再恢复上次的信息页。正常关机时重新预写到键盘共用的自定义图片槽，供下次电脑端程序接管前循环播放。温度页不占用该图片槽，Codex 图片会覆盖它，因此关机时可能需要重新传输。36 帧经 2.4GHz 实测上传约 17 秒，预写期间会暂缓正常关机；强制关机或断电无法保证完成。

跑马灯与 `<SYSTEM BOOTING>` 文字的可见边界左右对齐，宽度均为 126 像素。

苹果图标来自 [Simple Icons 11.0.0](https://cdn.jsdelivr.net/npm/simple-icons@11.0.0/icons/apple.svg)，按 OLED 分辨率栅格化；源文件见 `apple-logo.svg`。该图标仅用于标识系统类型。
